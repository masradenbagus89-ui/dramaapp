# complexity-budget.md — Robot "Anggaran Kerumitan" (cuma-baca)

> Versi 1 · 2026-07-18 · pendamping `engine/complexity-budget.mjs`

## Tujuan
Memindai berkas kode (JS/TS + Python) untuk 2 sinyal **kerumitan kasar**: **berkas gemuk** (≥500 baris non-kosong) dan **fungsi/blok panjang** (badan ≥100 baris). Keduanya = sarang bug + bikin AI harus baca banyak (lambat + boros token + lebih mudah ngarang).

🏢 Analogi: seperti **rak yang kelewat penuh** — masih bisa dipakai, tapi cari barang jadi lama + gampang salah ambil. Robot cuma menempel stiker "rak ini kepenuhan, pertimbangkan dibagi", tidak memindahkan apa pun.

Standar industri sejati: **ESLint `max-lines`** + **`max-lines-per-function`** (dan SonarQube cognitive-complexity) menegakkan hal yang sama. Ide diadaptasi dari **Ponytail** (`github.com/DietrichGebert/ponytail`, MIT © 2026 DietrichGebert) — thesis "the best code is the code you never wrote" (YAGNI/anti-over-engineering) — ditulis ulang untuk Node + Bahasa Indonesia non-programmer.

> **Kenapa robot ini ada padahal ESLint sudah punya `max-lines`?** Karena `max-lines` + `max-lines-per-function` **MATI-default** di ESLint — mayoritas project tak pernah menyalakannya. Robot ini memberi penjaga ukuran **tanpa setup linter apa pun** (penting untuk tim non-programmer). Kalau ESLint `max-*` sudah dipasang (via `stack-check`), itu yang otoritatif.

## Yang SENGAJA TIDAK dipindai (anti-asal-flag §8.2-3b)
Robot ini **bukan linter penuh**. Sinyal berikut **sengaja dibuang** karena terlalu berisik (banyak alarm-palsu):
- **Kode mati / export tak terpakai** — bisa dipanggil dari tempat lain yang belum dicek (jebakan §8.2-3b(a)).
- **Blok duplikat** — butuh ambang kemiripan; berisik.
- **Abstraksi spekulatif** — butuh analisa call-graph.
Itu tetap **urusan nalar AI** baca `templates/REFACTOR_STANDARD.md`, bukan robot. Robot cuma kasih **fakta** (lokasi + jumlah baris); **vonis** "ini over-engineering" tetap di AI (nalar, BUKAN router — ADR-009). **Tanpa** skor-angka gabungan (§8.2-3b anti skor-biner).

## File auto-generate DIBUANG (kunci: anti alarm-palsu masif)
Kode hasil-generate (Prisma models, Supabase `database.types.ts`, `*.d.ts`) sering **ribuan baris** tapi **tak pernah diedit manusia** → menandainya = alarm-palsu. `isGenerated()` membuangnya lewat:
- **Path:** `*.d.ts` atau folder `/generated/`.
- **Endus-header** (5 baris pertama): `code generated` · `auto-generated` · `@generated` · `do not edit` · `jangan edit` · `generated by`.

Uji lapangan (2026-07-18) membuktikan ini penting: di project `akses`, **40 dari ~46 berkas ≥500 baris = Prisma auto-generate** (`User.ts` 4397 baris, dll). Tanpa pembuangan ini, ~85% temuan = derau. Bukti filter aman: **40/40** file `src/generated/` ber-penanda, **0** file tulisan-tangan ber-penanda. Jumlah yang dibuang **dilaporkan** ("N file auto-generate dilewati"), tak disembunyikan (anti-derau-senyap §6.3).

## 🔒 Keamanan (WAJIB)
**Cuma-baca**: hanya membaca berkas + menghitung baris/kurung. Tidak menulis/mengubah/menjalankan kode, tidak ke jaringan. Laporan hanya lokasi + jumlah baris. Dikunci `tests/complexity-budget.test.mjs` (termasuk uji "memindai tak mengubah berkas").

## Cara Pakai
```bash
npx lintasai complexity-budget                          # pindai folder kerja
npx lintasai complexity-budget src/ lib/besar.js        # path tertentu
npx lintasai complexity-budget --file-lines 400 --func-lines 80   # ambang kustom
npx lintasai complexity-budget --json
```
Juga jalan otomatis di Gerbang Pra-Rilis (`npm run preflight`) sebagai **SARAN**.

## Mode (keputusan penting, §4.6)
Level **RAPIKAN** — **tak pernah memblokir** gerbang, bahkan `--strict`. Alasan: mutu-kode **bisa-dibalik** (biaya salah-blok > kelewat) + robot baru **belum punya angka laju-alarm-palsu**. Naik ke pemblokir HANYA setelah ada evaluasi. Di **MODE KIT** (memindai kit sendiri yang tooling-nya memang besar — `update-kit.mjs` 1233 baris dll) temuan diturunkan ke **INFO** supaya tak menyandera Gerbang 0/0/0 kit; di **MODE PROJECT** (app klien) tetap RAPIKAN.

## Cara kerja singkat
**Berkas gemuk** = hitung baris non-kosong (teks asli). **Fungsi/blok panjang** = cari pembuka-badan `) {` / `=> {` (JS) atau header `def` (Python), ukur rentang barisnya; objek-literal (`= {`) tak dihitung (bukan blok logika). Teks **di-samar** dulu (isi string→spasi, komentar→pengisi) — reuse `maskJs`/`maskPy` dari `swallowed-error-check.mjs` — supaya `{`/`def` di dalam teks tak memicu. Blok **bersarang** dilaporkan yang terluar saja (anti dobel).

## Batas jujur (bukan bug)
- **Bukan pengganti linter.** Kalau ESLint/ruff `max-*` sudah dipasang, itu yang otoritatif. Nilai robot ini: **jalan tanpa setup linter apa pun**.
- Ambang default = **langit-langit anti-regresi**, bukan target ideal (§5 ideal <300 baris). Bisa di-set via `--file-lines`/`--func-lines`.
- Deteksi "fungsi" via kurung/indentasi = **perkiraan**, bukan parser bahasa penuh (gaya definisi langka bisa terlewat) — cukup untuk pemeriksa SARAN.

## Dependensi
Node 18+. Tanpa modul eksternal. Reuse `readTextSafe` (`fs-text.mjs`) + `maskJs`/`maskPy`/`listCodeFiles` (`swallowed-error-check.mjs`).
