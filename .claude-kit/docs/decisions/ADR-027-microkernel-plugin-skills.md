## Context

`CLAUDE_universal_v1.md` dibaca **tiap sesi** oleh tiap client (rantai `CLAUDE.md.template:12-13` → `@./.claude-kit/CLAUDE_universal_v1.md`). Bukti [[ADR-023]]: daftar besar yang selalu-dimuat justru **MEMECAH perhatian** AI (bukan cuma boros token).

**Pola lama = anti-pattern bernama:** *Eager-Loaded Monolith / God-Context / Context-Stuffing* — muat semua di depan, dipakai atau tidak.

Owner ingin: **hemat token · AI benar menganalisa · AI cepat+gesit · mudah maintenance (skala ~100 skill) · web+app powerful · cocok di harness apa pun** — tanpa ubah fungsi & tanpa merusak client.

## Decision

Adopsi **Microkernel + Plugin** (a.k.a. *Plugin Architecture*) dengan *Lazy Loading + Progressive Disclosure*:

- **KERNEL (always-load, ~7k token, irreducible):** hanya yang berlaku ke SETIAP aksi (*cross-cutting concern*, dijalin ala AOP) — Bahasa non-programmer §2.1 · Anti-halusinasi §8.2 · Peta-Dampak §7.3a · Uji-Profesional §1 · Advisory §4.17 · **REGISTRY index-divisi**. *Uji keanggotaan kernel:* masuk HANYA jika (a) cross-cutting DAN (b) ketiadaannya diam-diam merusak keselamatan.
- **PLUGIN / SKILL (lazy, di `skills/`):** buku panduan bidang, **self-registering** via frontmatter, **auto-aktif** dari prompt, bersifat **advisory** (otak native yang memutuskan — adopsi/adaptasi/abaikan). Standar mutu = **5-label owner** (🔒 HASIL · 📐 CARA BAKU · 💡 SARAN · 🧪 CONTOH · 🗃️ LATAR) + checklist kelengkapan (Kontrak/Powerful/DoD/Self-verify/Handoff/Analogi). Boleh membawa **scaffold** (generator kode).
- **DISPATCHER (deterministik, ~0 token):** `rak-pemicu` membaca prompt → menunjuk skill relevan (multi-divisi), **menjamin skill keamanan muncul** (rawan-keamanan = wajib-baca via `rak-gate`). Aditif — nol-cocok → perilaku persis seperti sebelumnya.
- **Advisory 2-level:** BACA (skill biasa opsional; rawan-keamanan wajib) · IKUT (cara boleh diabaikan §4.17; HASIL keselamatan dijamin kernel §8/§8.2).

### Agnostik lintas-harness (3-lapis)
- **KONTEN** (kernel/PETA/skills/registry/rules = markdown+JSON) → jalan di AI apa pun.
- **ENTRY** adapter per-harness → konten SAMA: Claude→`CLAUDE.md` · Codex→`AGENTS.md` · Kimi→`.kimi-code/` · Cursor→`.cursor/rules`.
- **AUTOMASI** (hook) = akselerator opsional; di harness tanpa hook, AI navigasi manual lewat PETA+registry → **nol crash, cuma kurang otomatis**. Logika dispatcher hidup sbg KONTEN (registry+PETA), bukan cuma hook.

## Consequences

**Positif (jujur):**
- **lintasAI (paling pasti):** maintainability + skala 100 skill (tambah skill = 1 berkas, bukan edit monolith + navigasi silang-rujuk).
- **AI:** perhatian fokus (sembuhkan pemecahan-perhatian [[ADR-023]]) → analisa lebih benar; navigasi via PETA+registry (indeks O(1)) → eksekusi cepat; konteks ramping → hemat token.
- **Client (potensi besar):** scaffold → delivery web+app cepat; update mulus; cocok di harness apa pun.

**Jujur soal batas:**
- **Hemat token = MODEST** untuk always-load (kena prompt-cache; hemat per-sesi kecil). Hemat sejati = flat-saat-skala + hindari baca-besar-tak-sengaja. RINGAN (Tugas 1-5) bahkan **net-menambah** karena guard+konvensi > relokasi aman — angka nyata Tugas 1-4: ~15.872 → ~16.049 token.
- **Akurasi = TERBUKTI-DI-MEKANISME (Tugas 11), bukan di-analisa-AI.** Pilot membuktikan dispatcher deterministik menyalakan plugin lewat hook NYATA end-to-end (bukan mock). Apakah AI *menganalisa lebih benar* karena konteks fokus = belum diukur (butuh perbandingan output lintas-sesi); yang terbukti = **rute + guard + additivitas**. Lihat "Gerbang Pilot" di bawah.
- Migrasi ~40 skill + rename 226+ ref = churn besar; dijaga tes parity + 1.200+ tes + preflight.

## Alternatif yang DITOLAK (untuk syarat ini)
- **RAG / retrieval semantik:** fuzzy → bisa lewatkan aturan keselamatan (= ubah fungsi); butuh infra + non-deterministik. Deterministik > fuzzy untuk sistem yang keselamatannya wajib.
- **LLM-as-router:** lambat + mahal + tak pasti; kalah dari dispatcher regex ~0 token.
- **AOT tree-shaking per-stack:** deterministik & bagus, tapi kit sudah pisah universal (always-load) vs stack-spesifik (on-demand) → sedikit yang bisa dipangkas. Pelengkap, bukan pengganti.
- **Lazy-load pagar keselamatan:** DITOLAK — pagar = cross-cutting, dijalin bukan di-lazy-load; regex-miss = kerentanan senyap.
