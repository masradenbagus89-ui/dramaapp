## 4.15. 4 Pola Bantu Staff Non-Programmer (otomatis, kini jadi skill) — hub: Perbaiki Error · Cakupan Tes · Pindai Permukaan-AI · Tahan-Gagal

> Pinjam pola ECC v2.0.0 (MIT): `build-fix`, `test-coverage`, `security-scan`/`mcp-inventory` — ditulis-ulang jadi **pola kerja AI** gaya non-programmer (lintasAI digerakkan aturan, bukan skrip terpisah). On-demand: tiap pola kini jadi **skill mandiri** di `skills/<nama>/SKILL.md`, dinyalakan sesuai pemicunya (hemat token — 1 skill, bukan 4 sekaligus).

### 5 pola — baca berkasnya sesuai pemicu

| Pola (kini skill) | Pemicu | Skill |
|---|---|---|
| 🔧 **Perbaiki Error** Build/Run | "error", "gagal build", "merah", "crash", "tidak jalan" | `skills/perbaiki-error/SKILL.md` |
| ✅ **Cakupan Tes** + bikinkan tes kurang | "tes", "coverage", "pastikan teruji"; sehabis bikin fitur | `skills/cakupan-tes/SKILL.md` |
| 🔒 Pindai **Permukaan-AI** (MCP/izin/hook) | "audit keamanan AI", "cek MCP/izin", tambah/ubah skill-MCP | `skills/permukaan-ai/SKILL.md` |
| 🔁 **Tahan-Gagal** panggilan API luar (retry + circuit breaker) | kode panggil API luar rapuh (Supabase/Stripe/dll) | `skills/tahan-gagal/SKILL.md` |

> **Catatan (ADR-027 Fase Arsip, 2026-07-21):** 4 pola di atas kini jadi **skill** (`skills/<nama>/SKILL.md`), dinyalakan otomatis dispatcher `rak-pemicu` (Permukaan-AI & Tahan-Gagal) atau dirujuk saat relevan. Pola lama **Uji Situs** (browser-MCP) **dipensiunkan** (riwayatnya di git + ADR-027).

Otomatis sesuai pemicu — staff cukup prompt biasa, AI petakan ke pola yang cocok. Semua tunduk Gerbang §4.6 + anti-halusinasi §8.2 + aksi merusak konfirmasi (§8.2 Aturan 5).

> **Catatan owner — lihat biaya AI:** lintasAI SENGAJA tak pasang hook Claude Code (ADR-001) → pelacak biaya bawaan ECC SELALU kosong (= rasa-aman-palsu). Cara jujur pantau biaya: buka **Anthropic Console → Usage/Billing** (sumber biaya sebenarnya). Kalau butuh ringkasan biaya dalam kit = fitur 2-bagian (hook `Stop` sendiri + pembaca) = keputusan owner + ADR baru.
