## §7.3a — Task MODIFIKASI: dokumen untuk NAVIGASI, kode asli WAJIB dibaca sebelum edit (DETAIL on-demand)

> **§7.3a — WAJIB sebelum ubah/tambah/hapus kode apa pun (semua intent "fix/refactor/tambah/hapus" di tabel bawah):** dokumen & peta hanya untuk **NAVIGASI**. Setelah tahu berkas target, **WAJIB baca KODE ASLI berkas target + pemanggil langsung SEBELUM mengedit** — kode = kebenaran terkini, dokumen bisa basi; beda → **percaya kode** (lalu perbaiki dokumennya). Khusus **HAPUS** → `Grep` pemakaian nyata dulu (cegah crash). Penjaga gratis: Claude Code menolak `Edit` berkas yang belum di-`Read` (berkas target saja). Aturan penuh: `CLAUDE_universal_v1.md` §7.3a. 🏢 dokumen = Google Maps (tahu arah); kode asli = jalan sebenarnya (lihat sebelum belok — bisa ada jalan ditutup yang belum ter-update di peta).

**Checklist mikro pra-edit (§7.3a — 5 centang, jangan over-analisa):** (1) tahu berkas target? → navigasi ✔ (2) sudah `Read` kode asli target? → dipaksa Claude Code ✔ (3) sudah `Grep` pemanggil langsung? ✔ (4) mau HAPUS? → `Grep` pemakaian nyata dulu ✔ (5) dokumen ≠ kode? → percaya kode, perbaiki dokumennya ✔

Aturan inti 4-langkah + pengunci tes: `CLAUDE_universal_v1.md` §7.3a. Dipakai otomatis untuk SEMUA intent fix/refactor/tambah/hapus di `rules/4.2-pattern-driven.md`.
