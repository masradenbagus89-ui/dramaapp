### §7.6 AI Auto-Health-Check — detail kapan-jalan + yang dicek

> Dipindah dari `CLAUDE_universal_v1.md` §7.6 (pemicu inti tetap di sana). Dibaca saat menjalankan health-check.

**Kapan jalan (default hemat):**
- (a) **sesi PERTAMA setelah pasang/update kit** → jalankan penuh + tampilkan inline + tawarkan fix otomatis (user klik Y → AI fix via Bash, TIDAK perlu buka CLI manual).
- (b) **REAKTIF** — begitu ada tool error pertama yang berbau lingkungan (modul tak ketemu, versi Node aneh, dependensi hilang) ATAU user menyebut "di komputerku jalan, di sana beda" → jalankan penuh saat itu juga.
- (c) **manual** — user minta "health-check" / `npx lintasai doctor` kapan pun.
- Di luar 3 pemicu itu JANGAN auto-jalan tiap sesi (hemat ±500 token/sesi; sesi normal langsung kerja).

**Yang dicek:** (1) `.claude-kit/` lengkap (sha256 match) · (2) `.github/staff-roster.yml` ada + email terdaftar — **roster masih placeholder `@example.com` = FRESH-INSTALL NORMAL: tawarkan isi email asli, JANGAN lapor seolah rusak** · (3) `.env.local` (kalau project butuh) · (4) `node_modules` (kalau ada package.json) · (5) hook penjaga milik project (mis. `.claude/hooks/tier-guard.mjs`) — **OPSIONAL, kit tak memasangnya; tak ada = BUKAN error.** JANGAN klaim ada hook MEMBLOKIR tanpa MEMBUKTIKAN berkasnya ADA (§8.2 "no quote = no claim"); TERBUKTI ada + nyata memblokir = KEAMANAN ASLI user: HORMATI (§8.1 #4) · (6) **Lingkungan eksekusi** — `npx lintasai doctor` memotret versi Node/OS/Git + `node_modules`/lockfile (cuma-baca, TIDAK membaca isi `.env`; robot `lib/env-check.mjs`; matikan `--no-env`).

🏢 Analogi: kayak iPhone notif "Storage penuh, hapus video lama?" — iPhone yang scan + tawarkan fix, user cuma klik [Allow].
