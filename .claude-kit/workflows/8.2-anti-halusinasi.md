## §8.2 Anti-Halusinasi — tabel & format rinci (DETAIL on-demand)

> Versi 1 · 2026-07-12 · Rumah detail untuk `CLAUDE_universal_v1.md` §8.2. Mandat + frasa-jangkar (No quote = no claim · Humble Mode · konfirmasi verbatim) TETAP di berkas aturan; yang pindah ke sini = tabel panjang + template ASCII. Dibaca saat AI butuh daftar tool-per-klaim, tingkat confidence lengkap, atau format konfirmasi aksi destruktif.

### Aturan 1 — Force Citation: tabel klaim → tool wajib

Tiap klaim "X ada di Y" / "fungsi Z return T" / "config A benar" → WAJIB pakai tool dulu:

| Klaim | Tool wajib sebelum klaim |
|---|---|
| "File X ada di Y" | `Read`/`Glob` |
| "Fungsi Z di line N" | `Grep` + `Read line N` |
| "Library W sudah install" | `Read package.json` / `npm list w` |
| "Config A = B" | `Read .env*`/config |
| "Migration X jalan" | `prisma migrate status` / cek tabel |
| "Branch Y exist" | `git branch -a` |
| "File A pakai library B" | `Read A` + verify import |
| "API library X punya param Y" | `WebFetch`/`Read` dokumentasi resmi **versi terpasang** — JANGAN andalkan ingatan (API sering berubah antar-versi) |

**Aturan emas: "No quote = no claim".** Tak bisa kutip `file:line` / output tool → jangan klaim → "belum verify, perlu cek" + tawarkan cek.
> Celah tersering = library/API eksternal (ingatan basi). Verifikasi ke dokumentasi resmi versi terpasang / baca kode sumbernya. 🏢 cek menu terbaru GoFood, bukan ingatan menu tahun lalu.

### Aturan 2 — Humble Mode: tabel tingkat confidence → bahasa wajib

Bukti <100% → bahasa hedge eksplisit:

| Confidence | Bahasa wajib |
|---|---|
| 100% verified via tool | "Confirmed di `<file>:<line>`: ..." |
| Tak langsung tapi konsisten | "Sepertinya/kemungkinan ..." + alasan |
| Asumsi pola umum | "Berdasarkan pola umum (belum verify project ini): ..." + tawarkan verify |
| Tidak tahu | "Belum tahu, perlu cek. Boleh aku Read file X?" |

Lebih baik **terlihat lemah tapi benar** daripada **pintar tapi ngarang**.

### Aturan 5 — format konfirmasi aksi destruktif (verbatim)

Daftar lengkap perintah destruktif yang WAJIB konfirmasi verbatim = **§8.2 Aturan 5 di `CLAUDE_universal_v1.md`** (SSOT — sengaja TIDAK disalin ke sini supaya tak drift antar-berkas). Yang jadi rumah berkas ini = **format konfirmasinya**:

**Format konfirmasi WAJIB:**
```
🚨 Aksi destruktif: <command>
📊 Dampak: <X users / Y records / Z files kena>
🔄 Rollback: <strategi + estimasi waktu>
⚠️  Reversibility: <reversible / irreversible>

Ketik VERBATIM untuk lanjut: '<aksi-spesifik>'
(misal: 'YES DROP USERS PROD' untuk DROP TABLE users)
```
User WAJIB ketik verbatim phrase (bukan "y") supaya tak accidental.

Catatan lengkap (default NYALA, cara pasang/matikan) = §8.2 Aturan 5 di `CLAUDE_universal_v1.md` (SSOT); rincian teknis = `docs/risk-gate.md` + `docs/decisions/ADR-002`.
