## 8.3 Trusted Repo Auto-Detect (GPG Verification Skip) + Audit Log

> **Berlaku untuk jalur repo (owner `--from-repo`) SAJA.** Sejak v2.8.0 (§4.5), staff biasa update via `npx lintasai@latest update` dari paket npm — **TANPA git/GPG**. Jadi warning GPG di bawah TIDAK muncul di alur staff normal; mekanisme trusted-repo ini relevan hanya saat owner/tim ber-akses repo meng-update dari klon git (`--from-repo`).

**Masalah (jalur repo):** `git verify-tag` GPG bisa gagal di mesin yang belum meng-import pubkey owner → warning `[FAIL] Tag bukan GPG-signed valid`; fail-closed bikin stuck, atau bypass bikin security theater (warning selalu ada → diabaikan).

### Filosofi: layered trust (3-layer source integrity)

| Layer | Purpose | Bypass |
|---|---|---|
| **1. HTTPS + TLS** | Transport integrity (anti-MITM saat clone) | Tidak bisa (built-in git) |
| **2. RepoUrl allowlist** | Source authenticity (clone dari mana) | `--allow-untrusted-repo` (warn + audit) |
| **3. GPG verify-tag** | Author authenticity (siapa sign release) | `--allow-unsigned-tag` (warn + audit) atau trusted repo auto-skip |

Trusted repo whitelist = **defense-in-depth optimization**, BUKAN trust reduction. Untuk owner repo resmi (`github.com/ojokesusu/lintasAI`), Layer 1+2 sudah cukup; GPG di-skip eksplisit + transparan (audit log).

### Trusted repo whitelist (default + override)

Default hardcode di `update-kit.mjs` (URL `ojokesusu/lintasAI` 3 bentuk: HTTPS, HTTPS-tanpa-`.git`, SSH). Override fork private/mirror via env var comma-separated **sebelum** perintah: `$env:LINTASAI_TRUSTED_REPOS = '<url1>,<url2>'`. URL dibandingkan case-insensitive + trailing `/` dan `.git` di-strip.

### Alur eksekusi (Step 2b, GPG block)
`testTrustedRepo(repoUrl)` → **match whitelist**: `[OK] ... (trusted, GPG skipped)` + audit `gpg-check-skipped`, lanjut. **Di luar whitelist**: GPG verify-tag → sukses `gpg-check-passed`; gagal tanpa `--allow-unsigned-tag` = fail-closed (BATAL); gagal dengan flag = warn+lanjut `gpg-check-bypassed`.

### Audit log (`.audit-log`)

Lokasi `<kitDir>/.audit-log`. Format per baris (ISO 8601 UTC): `<TIMESTAMP> | <SOURCE> | <ACTION> | <DETAIL>`. Contoh action: `gpg-check-skipped ... reason=trusted-repo-whitelist` · `gpg-check-passed ... tag=v1.5.1` · `gpg-check-bypassed ... reason=allow-unsigned-tag-flag UNSAFE=true`. Append-only, plain text (grep-able); **tidak di-rotate otomatis** (volume kecil, retention manual owner).

### Catatan keamanan

- **Audit log = local only**, tidak di-commit (`.gitignore`).
- **Audit log gagal != fatal** (disk full/permission → warn, update lanjut; transparency ≠ availability).
- **Owner paksa GPG verify**: set `$env:LINTASAI_TRUSTED_REPOS = ''` + hapus entry default `$TrustedRepos` di local fork.
- **Whitelist ≠ substitute allowlist** (`$allowedRepoUrls`): allowlist gate clone source, trusted whitelist gate GPG skip.

### Trade-off divisi

- **Security**: trust shifted GPG → HTTPS+TLS+GitHub branch protection. RISKY kalau staff salah set `LINTASAI_TRUSTED_REPOS` ke fork ter-compromise.
- **UX**: zero warning palsu untuk update normal (friction turun).
- **Audit/Compliance**: full transparency via `.audit-log` (timestamp + reason, owner review periodic).
- **DevOps**: env var memungkinkan CI pakai fork mirror internal tanpa modify script.
