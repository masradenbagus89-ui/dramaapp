Arsitektur

Trik hemat biaya: pisahkan aplikasi & video

[ Penonton (HP / Komputer) ] │ ▼ [ Vercel ] ── aplikasi: katalog, halaman, API → gratis, selalu online │ │ (untuk video, diarahkan ke...) ▼ [ PC Backup ] ── menyimpan file video asli (ukuran besar) │ └─ Caddy + Tunnel ── menyalurkan video ke penonton
  • Masalah: file video besar — tak muat di hosting gratis biasa.
  • Solusi: aplikasi ringan di Vercel, video tetap di PC dan disalurkan lewat tunnel.
  • Hasil: biaya hosting Rp 0, aplikasi tetap cepat & selalu online.

07 · Fitur Penontondramaapp.vercel.app
Monetisasi

Sistem koin — siap menghasilkan

  • Episode premium: beberapa episode awal gratis, sisanya dibuka pakai koin.
  • Dapat koin: tonton iklan berhadiah, atau check-in harian.
  • Beli koin: kerangka top-up sudah disiapkan (siap disambungkan ke pembayaran).
  • Aman: saldo & pembukaan episode dicatat di server, bukan di HP penonton.

Pondasi bisnis sudah ada — tinggal diaktifkan saat siap dikomersialkan.

09 · Panel Admindramaapp.vercel.app
Keamanan

Keamanan tingkat profesional

🔒 Verifikasi di server

Hak admin dicek ulang di server pada setiap aksi — tak bisa "mengaku admin" lewat browser.

🛡️ 2FA (TOTP)

Login admin bisa pakai kode dari Google Authenticator — lapisan keamanan kedua.

🩹 Kerentanan ditambal

Next.js dinaikkan ke 16.2.9 menutup celah keamanan tingkat tinggi.

🚪 Default tertutup

Tanpa izin yang benar = ditolak. Rahasia (kunci) tak pernah masuk kode.

Antisipasi Pertanyaan

Q & A singkat

Berapa biaya menjalankan ini?
Rp 0 / bulan untuk sekarang — Vercel gratis untuk aplikasi, video di PC sendiri, semua tool open-source.
Apakah aman dipakai publik?
Ya — hak akses diverifikasi di server, login admin bisa 2FA, dan celah keamanan terbaru sudah ditambal.

AI membantu menulis, memeriksa, dan merapikan kode mengikuti standar tim — sehingga satu orang bisa menghasilkan produk berkualitas tim.
